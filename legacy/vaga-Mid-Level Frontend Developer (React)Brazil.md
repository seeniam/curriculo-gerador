Estamos procurando um Desenvolvedor Frontend

Buscamos um Frontend Developer para construir interfaces web modernas para uma plataforma baseada em nuvem.

Esta função tem foco em criar interfaces intuitivas, acessíveis e escaláveis, capazes de suportar fluxos de trabalho complexos e integrações corporativas.

Você trabalhará em colaboração próxima com designers, engenheiros backend e equipes de produto para entregar experiências frontend de alta qualidade.

Sua missão

Desenvolver interfaces web modernas que proporcionem uma experiência de usuário fluida.

Traduzir requisitos de produto e design em componentes frontend reutilizáveis e escaláveis.

Garantir que as aplicações frontend permaneçam performáticas, acessíveis e fáceis de manter.

Colaborar com engenheiros backend para integrar APIs e manter contratos de dados consistentes.

Principais responsabilidades

Desenvolver aplicações frontend usando React.

Criar componentes de interface reutilizáveis e manter padrões consistentes de design.

Integrar funcionalidades do frontend com APIs REST.

Implementar layouts responsivos e experiências interativas.

Escrever testes frontend, incluindo:

testes unitários

testes de componentes

testes end-to-end

Garantir padrões de acessibilidade e boas práticas de usabilidade.

Otimizar performance e manutenção do frontend.

Colaborar com product managers, designers e desenvolvedores backend para entregar novas funcionalidades.

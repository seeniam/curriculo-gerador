About the Role

We are looking for a motivated Junior React Native Developer to help support, refine, and scale our mobile applications for iOS and Android. This isn't just a "shadowing" role—you will be working directly with production code, resolving real-world issues, and shipping new features.

If you are early in your career but already have a few "wins" under your belt (like a published app), this is the perfect place to fast-track your growth in a professional, remote environment.

What You’ll Do

Feature Development: Build and enhance mobile features using React Native and TypeScript.
UI/UX Refinement: Assist in polishing iOS layouts to ensure a high-quality, native feel.
Problem Solving: Troubleshoot bugs and improve app reliability/performance.
Full Lifecycle: Test fixes across both iOS and Android environments and work within our existing architecture to improve code quality over time.
Required Qualifications

Technical Stack: Proven experience with React Native CLI and TypeScript.
Portfolio: At least one mobile application currently live on the Apple App Store or Google Play Store.
Eye for Detail: Basic familiarity with iOS interface patterns and responsive layouts.
Reliability: Ability to follow technical instructions, debug effectively, and work independently in a fully remote setup.
Communication: Proficiency in English.
Preferred Experience

Previous internships, freelance gigs, or significant personal projects.
A baseline understanding of performance optimization.
Interest in IoT or apps that interact with hardware.

Sua Missão:

Buscamos um(a) desenvolvedor(a) FullStack Pleno para se juntar à nossa equipe e atuar na construção de aplicações modernas, escaláveis e orientadas a dados, alocado em um de nossos clientes. Esse profissional irá desenvolver e integrar aplicações front-end e back-end, colaborar com times de engenharia e dados e participar da criação de soluções que utilizam Generative AI, APIs e arquiteturas cloud-native, garantindo qualidade, performance e boas práticas de desenvolvimento.

Principais Atividades:

Desenvolver aplicações front-end responsivas e de alto desempenho utilizando JavaScript/TypeScript com React ou Next.js.
Construir e manter APIs RESTful ou GraphQL e serviços back-end utilizando Python (FastAPI, Django) ou Node.js (Express, NestJS).
Integrar aplicações com sistemas de Generative AI, incluindo LLM APIs, interfaces de chat, streaming de respostas (SSE/WebSockets) e fluxos de processamento de documentos.
Modelar e manter bancos de dados SQL e NoSQL, garantindo qualidade, performance e escalabilidade das aplicações.
Implementar mecanismos de autenticação e autorização seguros utilizando padrões como OAuth 2.0 e JWT.
Participar da construção e manutenção de pipelines CI/CD e ambientes containerizados utilizando Docker, GitHub Actions ou ferramentas similares.
Colaborar com times de AI e Data Engineering para integrar serviços, APIs e pipelines de dados nas aplicações.
Participar de code reviews, discussões técnicas e cerimônias ágeis, contribuindo para a qualidade do código e evolução das soluções.
Atuar na otimização de performance, escalabilidade e experiência do usuário nas aplicações desenvolvidas.

Requisitos essenciais:

2–4 anos de experiência em desenvolvimento FullStack, com aplicações em produção.
Proficiência em Python e JavaScript/TypeScript.
Experiência com frameworks front-end modernos como React ou Next.js.
Experiência com frameworks back-end como FastAPI, Django, Flask, Express ou NestJS.
Experiência com bancos de dados SQL e NoSQL (PostgreSQL, MySQL, MongoDB, Redis).
Vivência com cloud computing em pelo menos um provedor (AWS, Azure ou GCP).
Experiência com integração de APIs e desenvolvimento de aplicações cloud-native escaláveis.
Conhecimento em CI/CD, versionamento com Git e pipelines automatizados.
Experiência com containerização utilizando Docker.
Familiaridade com padrões de autenticação e autorização (OAuth 2.0, JWT).
Inglês avançado para atuação em ambiente internacional.

Será um diferencial:

Experiência com soluções de Generative AI, como pipelines de RAG ou sistemas baseados em agentes.
Experiência com integração de APIs de LLMs (OpenAI, Azure OpenAI, AWS Bedrock ou Vertex AI).
Conhecimento em vector databases ou busca semântica.
Experiência com arquitetura de microsserviços ou serverless.
Familiaridade com mensageria (Kafka, RabbitMQ ou Redis Streams).
Experiência com frameworks de testes como Jest, Pytest ou Cypress.
Noções de Kubernetes.

Dev Pleno - Web & Mobile

Buscamos um(a) desenvolvedor(a) Fullstack/Mobile que não apenas escreva código, mas que tenha orgulho da entrega. Você atuará na evolução de sistemas modernos (React, Node.js, Firebase), com espaço real para questionar processos e sugerir melhorias de usabilidade.

Procuramos alguém com senso crítico de design: que se sinta incomodado com um alinhamento torto ou uma transição travada e que busque sempre a melhor experiência para o usuário final, indo além do "apenas funcional". Há uma perspectiva clara de crescimento para liderança técnica em curto/médio prazo.

O que buscamos (Requisitos)
• Domínio Técnico: Experiência sólida com React, TypeScript e Node.js.
• Refinamento Visual: Olhar apurado para HTML/CSS, garantindo interfaces responsivas e fiéis ao design (pixel-perfect).
• Qualidade de Software: Prática com Hooks, Redux, Jest, TDD, Clean Code e princípios SOLID.
• Mentalidade de Produto: Capacidade de entender o "porquê" das tarefas e propor soluções que agreguem valor real, fugindo do bare-minimum.
• Ferramental: Domínio de Git, APIs REST.

Diferenciais que valorizamos
•	Experiência com Android Studio e desenvolvimento mobile nativo/híbrido.
•	Vivência com serviços Cloud (GCP/Firebase).
•	Interesse ou experiência em integrar Agentes de IA às funcionalidades do produto.
• Inglês intermediário para documentação técnica.

Benefícios
•	Trabalho 100% Home Office com horários flexíveis.
•	Ambiente de aprendizado contínuo e autonomia para inovar.

Sobre a vaga
A Alpha7 Desenvolvimento de Software é referência em soluções de gestão avançada para drogarias. Há 15 anos transformando a gestão de farmácias no Brasil.
Estamos em busca de novos talentos para o nosso time de Desenvolvimento.


Responsabilidades e Atribuições:

Programar na linguagem Java, escrever código limpo utilizando a especificação Java EE, banco de dados PostgreSQL;
Participar de projetos, em conjunto com a equipe, utilizando metodologias e técnicas adequadas e indicadas ao desenvolvimento dos projetos;
Participar dos eventos relacionados ao framework Scrum tais como: Sprint Planning, Sprint, Daily Scrum, Retrospective, Sprint Review;
Realizar testes e simulações em condições operacionais, assegurando o funcionamento do programa;
Realizar o versionamento do código fonte, utilizando ferramenta de Controle de Versões;
Participar na revisão de código.


Requisitos e Qualificações:

Graduação em Ciência da Computação, Tecnologia da Informação ou áreas afins;
Experiência sólida como Programador Java; uso da linguagem Java para desktop;
Experiência com Java Swing;
Conhecimento na plataforma Java SE e Java EE;
Habilidade com sistemas de controle de versão, como Git;
Bancos de dados PostgreSQL;
Lógica de programação orientada a objetos (POO);
JPA (preferencialmente Hibernate);
Enterprise JavaBeans;
Vivência em times ágeis (Scrum).

Descrição completa da vaga
A primeira coisa que você precisa saber é que aqui você não vai cair na rotina. A Radix desenvolve soluções para empresas de diferentes setores e indústrias. Cada projeto tem suas tecnologias, soluções e prazos e você terá oportunidade de atuar e experimentar diferentes desafios. Além da nossa atuação pelo Brasil, com escritório no Rio de janeiro, São Paulo e Belo Horizonte, temos também filiais nos Estados Unidos, fazendo com que a Radix se consolide cada vez mais como uma empresa global.

Quer fazer parte dessa história e transformar ideias e sonhos em realidade?


Como Desenvolvedor de Software Júnior você vai:

Desenvolver e manter funcionalidades em aplicações web utilizando Angular (front-end) e Python com FastAPI (back-end).
Apoiar na construção e evolução de APIs para consumo de dados e integração entre sistemas.
Implementar interfaces web com foco em usabilidade e visualização de dados.
Auxiliar na integração de aplicações com plataformas de dados industriais, como Cognite Data Fusion.
Trabalhar na manipulação e exibição de dados provenientes de APIs e serviços backend.
Apoiar na identificação e correção de bugs.
Participar de code reviews e aplicar boas práticas de desenvolvimento.
Escrever código limpo, organizado e bem documentado.
Apoiar na criação de testes básicos para garantir a qualidade das entregas.
Colaborar com o time na evolução contínua das aplicações e processos de desenvolvimento.

Para essa vaga, você deve ter:

Conhecimento básico em desenvolvimento web (HTML, CSS, JavaScript).
Conhecimento básico em Angular (ou outro framework front-end).
Conhecimento básico em Python.
Noções de APIs REST.
Conhecimento básico em Git.
Lógica de programação e capacidade de aprendizado rápido.

É um diferencial se você tiver:

Experiência com Angular. 
Experiência com FastAPI ou outros frameworks Python (Flask, Django).
Conhecimento em consumo e construção de APIs.
Noções de bancos de dados (SQL ou NoSQL).
Interesse ou experiência com dados (visualização, dashboards, etc.).
Conhecimento básico de testes automatizados.
Noções de ambientes cloud (Azure).
Interesse em aprender sobre dados industriais e analytics.
